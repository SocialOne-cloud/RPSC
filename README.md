# RPSC — Rock. Paper. Scissor. Coke.

Mobile microsite for the Coca-Cola QR-code campaign: scan your opponent, play rock-paper-scissors, log the win.

- **App source:** [`app/`](./app) — React + Vite. See [`app/README.md`](./app/README.md) for setup, what's real vs. simulated, and Firebase pairing configuration.
- **Original design handoff:** [`project/`](./project) and [`chats/`](./chats) — the Claude Design mockup and chat transcript this build was implemented from. See [`DESIGN-HANDOFF.md`](./DESIGN-HANDOFF.md).
- **Live site:** deployed automatically to GitHub Pages on every push to `main` (see `.github/workflows/deploy.yml`) — check the repo's Pages settings for the URL once the first deploy completes.
